# دَون فيديو

أداة تحميل فيديوهات من أي موقع، تعمل محليًا على جهازك بواجهة عربية.
مبنية فوق [yt-dlp](https://github.com/yt-dlp/yt-dlp) الذي يدعم أكثر من ١٨٠٠ موقع،
بالإضافة إلى المستخرِج العام الذي يلتقط الفيديو من صفحات لا يدعمها بشكل خاص.

> **In English** — Dawn Video is a local, Arabic-first video downloader with a web UI,
> built on `yt-dlp`. Beyond the usual site support, it can drive a real Chrome instance
> over the DevTools Protocol to sniff media URLs out of JavaScript-rendered, login-gated
> pages (course platforms, SPAs) — capturing HLS/DASH manifests that never appear in the
> page source, then handing them to `yt-dlp` with the right cookies and referer.
> Zero npm dependencies: Node's standard library only. Runs on `127.0.0.1` and never
> listens on the network. Requires `yt-dlp` + `ffmpeg`.

---

## التشغيل

```bash
cd ~/"dawn video" && ./dawn
```

يفتح المتصفح تلقائيًا على `http://127.0.0.1:5178`.

للتحميل السريع من الطرفية مباشرة بدون واجهة:

```bash
cd ~/"dawn video" && ./dawn "https://www.youtube.com/watch?v=..."
```

لإيقاف الأداة: `Ctrl+C` في نافذة الطرفية.

## الاستخراج من الموقع

للمواقع المبنية بجافاسكربت (منصّات الدورات مثلًا) لا يوجد رابط فيديو في مصدر
الصفحة إطلاقًا، فلا يجد `yt-dlp` شيئًا. زر **استخراج من الموقع** يحلّ هذا:

1. الصق رابط صفحة الدرس واضغط **استخراج من الموقع**.
2. يفتح Chrome بملف تعريف مستقلّ خاص بالأداة — سجّل دخولك فيه أول مرة فقط.
3. شغّل الفيديو. الأداة تراقب طلبات الشبكة وتلتقط رابط الفيديو تلقائيًا.
4. يظهر الرابط في الأداة — اضغط **تحميل**.

تعمل عبر بروتوكول DevTools مباشرة (بدون أي حزمة npm)، وتتولّى تلقائيًا:

- **تصفية الإعلانات** — تتجاهل فيديوهات شبكات الإعلانات المعروفة
- **ترتيب النتائج** — ما يأتي من نفس نطاق الموقع يظهر أولًا بشارة «من الموقع»
- **تجاهل المقاطع** — تلتقط قائمة `m3u8` كاملة لا مئات المقاطع `.ts`
- **الكوكيز ورابط الإحالة** — يُضبطان تلقائيًا عند التحميل
- **تسمية الملف** — يستنتج اسم الدرس من مسار الرابط بدل `index.mp4`
- **البث المشفّر AES-128** — يمرّر الكوكيز إلى ffmpeg صراحةً (انظر أدناه)

### لماذا يلزم تمرير الكوكيز إلى ffmpeg

بث HLS المشفّر بـ AES-128 يُنزَّل عبر ffmpeg، و`yt-dlp` ينقل ترويسة `Cookie`
إلى جرّته الداخلية ولا يمرّرها إلى ffmpeg — فيرجع السيرفر `401` والنتيجة
`ffmpeg exited with code 8`. الأداة تحلّ ذلك بقراءة ملف الكوكيز وبناء ترويسة
`Cookie` للمضيف المطلوب وتمريرها عبر `--downloader-args ffmpeg_i:-headers`.

هذا تشفير HLS القياسي وليس DRM؛ لو كان الفيديو محميًا بـ Widevine فلن ينفع
أي من هذا، وسيفشل التحميل مهما كانت الإعدادات.

ملف تعريف المتصفح والكوكيز في `~/Library/Application Support/DawnVideo/`.
تُصدَّر كوكيز نطاق الموقع فقط لا كوكيز المتصفح كلها، بصلاحية `600`.
احذف المجلد لتسجيل الخروج من كل المواقع.

## المتطلبات

كلاهما مثبّت ويعمل على جهازك حاليًا:

| الأداة | الدور | التثبيت |
|---|---|---|
| `yt-dlp` | استخراج وتحميل الفيديو | `pip install -U yt-dlp` |

| Node.js ١٨+ | تشغيل الواجهة | مثبّت مسبقًا |

الحالة تظهر كشارات ملوّنة أعلى الواجهة، وتفاصيلها في لوحة الإعدادات.

## الإعدادات

من زر **الإعدادات** في الأعلى:

- **مجلد التحميل** — الافتراضي `~/Downloads/DawnVideo`
- **تحميلات متوازية** — كم فيديو ينزل في نفس الوقت (١–٦)
- **أجزاء متزامنة** — يرفع سرعة الفيديو الواحد (١–١٦)
- **تضمين الصورة المصغّرة وبيانات الملف**
- **أسماء ملفات لاتينية فقط** — مفيد عند نقل الملفات لأنظمة أخرى
- **تحديث yt-dlp** — يحدّثه بضغطة عند توقّف موقع عن العمل

تُحفظ في `config.json` بجانب الأداة.

## تسمية الملفات

```
العنوان [معرّف الفيديو] [الجودة].الامتداد
```

الجودة تُضاف فقط عند اختيار جودة محدّدة، و`[clip]` تُضاف عند قص مقطع.
السبب: لو حمّلت نفس الفيديو بجودتين، يبقى الملفان منفصلين بدل أن يتخطّى
`yt-dlp` التحميل الثاني ظنًّا أن الملف موجود.

## حلول للمشاكل الشائعة

**«الفيديو يتطلّب تسجيل دخول»**
فعّل ☑ «كوكيز المتصفح» واختر المتصفح الذي أنت مسجّل دخول فيه. أغلق المتصفح أولًا
إن كان Chrome، لأنه يقفل قاعدة الكوكيز أثناء عمله.

**«تعذّر استخراج فيديو من هذه الصفحة»**
غالبًا الموقع غيّر بنيته. اضغط **تحديث yt-dlp** من الإعدادات — أغلب الأعطال تُحلّ بذلك.

**«هذه الصفحة لا تحتوي على فيديو في مصدرها»**
مواقع كثيرة (خصوصًا منصّات الدورات) تُبنى بـ React/Vue: السيرفر يرسل صفحة فارغة،
والمحتوى يُركّب بجافاسكربت بعد تسجيل الدخول. `yt-dlp` لا يشغّل جافاسكربت، فلا يجد
شيئًا. الحل هو أخذ رابط الفيديو الحقيقي بنفسك:

1. افتح الدرس في المتصفح وشغّل الفيديو.
2. أدوات المطوّر `⌥⌘I` ← تبويب **Network**.
3. اكتب في الفلتر `m3u8` (بث مقطّع) أو `mp4` (ملف مباشر).
4. انقر يمينًا على الطلب الظاهر ← **Copy → Copy link address**.
5. الصق الرابط في الأداة، وفعّل ☑ **كوكيز المتصفح** و☑ **رابط الإحالة**
   (ضع فيه رابط صفحة الدرس) — أغلب سيرفرات الفيديو ترفض الطلبات بدونهما.

ملف `m3u8` ينزل كمقاطع ويُدمج تلقائيًا بـ ffmpeg إلى ملف واحد.

**«الجودة المطلوبة غير متوفّرة»**
اختر «أفضل جودة متاحة»، أو افتح **كل الصيغ المتاحة** واختر صيغة يدويًا.

**المنفذ مشغول**
```bash
PORT=5179 node server.js
```

## البنية

```
dawn video/
├── dawn            ← مشغّل (واجهة أو تحميل مباشر من الطرفية)
├── server.js       ← الخادم المحلي، يقود yt-dlp ويبثّ التقدّم عبر SSE
├── config.json     ← الإعدادات المحفوظة (يُنشأ تلقائيًا)
└── public/
    ├── index.html
    ├── style.css   ← يدعم الوضع الفاتح والداكن تلقائيًا
    └── app.js
```

الخادم بلا أي اعتماديات npm — Node وحده يكفي. ويستمع على `127.0.0.1` فقط،
أي أنه غير متاح لأي جهاز آخر على الشبكة.
